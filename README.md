# 게임 기획 포트폴리오 — v11 연구 리뷰 링크 추가

기존에 승인한 **v7 메인 레이아웃과 캐릭터 아트는 유지**하며, 사용자 피드백을 반영한 배포용 정적 웹사이트입니다. **게임 빌드 배포용이 아닙니다.**

## 이 버전에서 반영한 작동 방식

- 메인 배경: 외부 밤하늘 이미지를 넣지 않고 CSS로 차분한 남색 밤 분위기 + 매우 희미한 별빛 표현. 과한 반짝임 없음. 사용자가 동작 감소를 설정한 경우 애니메이션 중단.
- 실무 / 개인: 데스크톱 2열 사이에 **은은한 세로 구분선**. 1열로 바뀌는 화면에는 소박한 가로 구분선.
- **카드 전체와 제목/이미지를 클릭해도 이동하지 않음.** 카드에 마우스를 올리면 가벼운 하이라이트만. 향후 이미지 교체 기믹은 사용자가 개별적으로 요청할 경우에만 추가.
- **PDF 보기 버튼만 PDF 원본을 직접 새 탭에서 염.** `docs/` 경로 또는 HTTPS 파일 링크 지원.
- **영상 보기 버튼만 `project.html?id=...` 페이지로 이동.** 그 페이지에서 업로드된 로컬 MP4/WebM/OGV 파일을 HTML5 플레이어로 직접 재생. YouTube 및 외부 임베드 없음.
- 영상 상세 페이지에는 상단/하단 '포트폴리오 목록으로'와 연결된 PDF 버튼이 있습니다.
- 아직 등록되지 않은 영상이나 프로젝트 PDF는 `준비 중`으로 표기하며 클릭하지 못하도록 둡니다.

## 파일 구조

- `index.html`, `styles.css`, `app.js`, `data.js`: 메인 페이지 및 데이터
- `project.html`, `project.css`, `project.js`: 프로젝트별 **영상 재생 페이지**
- `assets/`: 사이트용 이미지 (그림 배경 대신 CSS 사용)
- `docs/경력기술서.pdf`: 기존 경력기술서 (공개용 파일)
- `docs/combat-prototype.pdf`, `docs/system-prototype.pdf`: 완료된 개인 프로토타입 사례 PDF 각 9쪽
- `media/combat-prototype.mp4`, `media/system-prototype.mp4`: 업로드된 대표 영상 각 1개
- `docs/`, `media/`: 이후 다른 프로젝트의 PDF·영상 추가 가능

## GitHub Pages 배포

1. 새 저장소 또는 이전 포트폴리오 전용 저장소를 사용하되, **기존 다른 웹사이트를 덮어쓰지 마세요**.
2. 이 ZIP의 *내용물을* 저장소 루트에 배치 (`index.html` 루트).
3. 저장소 `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)` 설정.
4. 실제 HTTPS 공개 URL에서 PC/모바일 디자인과 별빛 배경, 얇은 구분선, 카드 클릭 무반응, PDF/영상 버튼 동작을 검증하세요.

## 이후 콘텐츠 추가

1. PDF: `docs/판타지체스-기획.pdf` 등 파일 추가 → `data.js`의 해당 프로젝트 `pdfs[].href`에 실제 경로 입력. **메인 PDF 보기 버튼은 PDF를 직접 엽니다.**
2. 영상: `media/판타지체스-소개.mp4` 등 파일 추가 → `data.js`의 해당 프로젝트 `video.href`에 실제 경로 입력. **메인 영상 보기 버튼만 프로젝트별 재생 페이지로 이동합니다.**
3. 세부 페이지에서 동일 프로젝트의 PDF도 열람 가능. 한 프로젝트에 영상 1개, PDF는 여러 개 등록 가능.
4. 영상이 크면 GitHub 저장소 파일 크기/트래픽 정책을 먼저 검토하되, 임의로 YouTube 방식으로 전환하지 마세요.

**주의:** 외부 참고용 PDF, 개인 편집기 파일, 미승인 자료, 실제로 없는 영상/문서는 배포하지 마세요. `data.js`의 개발 단계 값은 잠정 표기이므로 최신 검증 없이 임의 변경하지 마세요.


## v10 — 기존 개인 프로젝트 목록에 프로토타입 통합 (2026-11-24)

기존 `개인 프로젝트` 목록 아래에 별도 섹션 없이 모두 같은 카드 디자인으로 표시합니다.

표시 순서 (`data.js`의 `order`):
1. 판타지 체스
2. Smash & Legacy
3. 눈동자 그녀 우주
4. 귀무자 전투 프로토타입
5. 성장·영토 확장 프로토타입

예전 `기획 검증 프로토타입` 소제목·구분선·축소형 카드 스타일을 제거했습니다. 과거 단기 프로토타입 두 개는 `category: 'personal'`로 합쳤으며, 이미 만든 단기 프로토타입에 현재 진행 중인 개발 단계 표시를 잘못 붙이지 않도록 `showProgress: false`를 사용합니다. PDF와 MP4는 변경 없이 유지됩니다.

- **귀무자 전투 프로토타입:** `media/combat-prototype.mp4` (약 12초), `docs/combat-prototype.pdf` (9쪽)
- **성장·영토 확장 프로토타입:** `media/system-prototype.mp4` (약 50초), `docs/system-prototype.pdf` (9쪽)

자료 버튼만 이동을 일으킵니다. PDF 버튼 → PDF 열람, 영상 버튼 → `project.html`의 HTML5 비디오 플레이어. 카드 전체·이미지·제목은 클릭해도 이동하지 않습니다.

이 압축파일의 **내용물 전체**를 기존 GitHub Pages 포트폴리오 저장소 루트에 업로드하면 됩니다. 다른 사이트나 게임 빌드를 변경할 필요는 없습니다.
