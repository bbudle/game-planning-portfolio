## 게시 및 갱신
1. 압축을 해제하여 모든 내용물을 GitHub Pages 저장소의 게시 루트에 복사합니다. 기존 사이트 경로를 유지합니다.
2. Settings → Pages에서 기존 게시 브랜치/폴더를 유지하고, 배포 완료 후 공개 URL에서 확인합니다.
3. PDF와 영상은 `docs/`, `media/`에 넣고 `data.js`의 해당 프로젝트 경로를 갱신합니다. 카드 제목/이미지는 이동하지 않으며 PDF/영상 버튼만 링크됩니다. 영상은 `project.html?id=...`에서 직접 재생됩니다.
4. 아직 제공되지 않은 영상 및 눈동자 그녀 우주의 자료는 준비 중으로 유지합니다.
