# 김재웅 · 게임 기획 포트폴리오 — v7 GitHub Pages 배포용

이 폴더는 **승인된 v7 포트폴리오 메인 디자인**에, 프로젝트 상세 페이지를 추가한 **정적 웹사이트**입니다. 게임 설치·실행 파일을 공개하는 저장소가 아닙니다.

## 구성

- `index.html`, `styles.css`, `app.js`, `data.js`: 기존 v7 메인 페이지. 카드 이미지 영역을 클릭하면 해당 상세 페이지로 이동합니다.
- `project.html`, `project.css`, `project.js`: 프로젝트별 상세 페이지. 상단 돌아가기 / 프로젝트 정보 / HTML5 영상 / PDF 링크.
- `assets/`: SD 및 기타 사이트 이미지 리소스.
- `docs/경력기술서.pdf`: 기존 경력기술서.
- `docs/`: 향후 프로젝트별 기획 PDF.
- `media/`: 향후 프로젝트별 대표 영상 MP4/WebM (현재 없음).

현재 대표 영상과 프로젝트별 PDF가 없어 해당 항목은 **준비 중**으로 표시합니다. 무관한 테스트 영상·PDF는 포함하지 않습니다.

## GitHub Pages 첫 배포

1. 새 GitHub 저장소를 생성합니다. 기존 사이트 저장소는 변경하지 않습니다.
2. 이 ZIP **안의 파일·폴더를 그대로 저장소 루트**에 업로드합니다 (ZIP 파일 1개만 업로드하는 방식 아님).
3. `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)`를 설정합니다.
4. 공개 URL에서 홈, 모든 카드의 상세 페이지, 뒤로가기, 경력기술서 PDF, 게임 기록지 링크, 모바일 레이아웃을 점검합니다.

## PDF와 대표 영상 추가 방법

- PDF 파일을 `docs/프로젝트명.pdf`에 넣고, `data.js`의 해당 프로젝트 `pdfs` 항목 `href: 'docs/프로젝트명.pdf'`로 수정합니다.
- 대표 영상은 YouTube 링크가 아닌 **파일 자체**를 `media/프로젝트명.mp4`(또는 `.webm`)에 넣고, 해당 프로젝트 `video.href: 'media/프로젝트명.mp4'`로 수정합니다.
- 상세 페이지는 `project.html?id=프로젝트ID` 형식으로 자동 출력합니다. 별도 HTML 페이지를 매번 만들 필요 없습니다.
- 영상은 자동재생하지 않고 페이지 안의 기본 HTML5 비디오 플레이어에서 직접 재생합니다. PDF는 상세 페이지 버튼을 클릭하면 새 탭에서 열립니다.
- 영상 1개, PDF 여러 개가 가능합니다. 실제 자료가 들어오기 전에는 링크를 임의 생성하지 않습니다.

**주의:** GitHub에는 파일 크기·저장소 권장 용량 제한이 있습니다. 대표 영상의 용량이 큰 경우 Git 담당자가 사전 용량·재생·전송 한계를 검토해야 합니다. 허락 없이 YouTube나 외부 임베드로 바꾸면 안 됩니다.

공개 저장소에는 개인 편집기, 원본 소스 아트, 다른 사람의 참고 PDF를 넣지 마세요. `data.js`에 적힌 개발 단계는 잠정 값이므로 사용자 검증 전 최신 개발 상태로 임의 업데이트하지 마세요.
